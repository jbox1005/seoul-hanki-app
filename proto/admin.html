앱을 새로 내지 않고 바꾸는 값. 앱은 켤 때 안내판을 읽어 이 값을 따릅니다. 서버를 옮길 때는 아래 주소만 바꾸고 올리기.
운영 구조 — 이 앱은 서버를 어떻게 찾고, 옮길 땐 어떻게 하나

뒤에 운영하는 사람을 위한 설명입니다. 코드를 몰라도 이 한 장으로 구조를 이해할 수 있게 적었습니다. (2026-08-27 확정)

한끼 앱 (PWA·스토어 앱 공통)
  │  앱 안에 박힌 값 = 안내판 주소 1개 (+예비 1개). 그것뿐.
  ▼ ① 켤 때 안내판을 읽는다
📌 안내판 (config.json)          ← 이 관리자 페이지가 고치는 파일   [절대 안 옮김]
  │  data: 데이터 서버 주소 / api: API 서버 주소 / 공지 / 띠 문구 / 신고 메일
  ▼ ② 안내판이 가리키는 곳으로 간다
🗂 데이터 서버 (자치구별 조각 json)     ⚙️ API 서버 (가입·후기·순위·건의)   [둘 다 옮겨도 됨]

왜 이렇게 하나

  • 스토어 앱은 서버 주소가 바뀌면 사용자가 업데이트할 때까지 먹통입니다. 그래서 주소를 앱에 직접 박지 않고, 절대 안 옮길 "안내판"만 박습니다.
  • 안내판은 깃허브 계정(IBK25237) 하나만 살아 있으면 영구입니다. 데이터·API 서버는 Cloudflare로 시작하고, 커지면 유료 전환이나 다른 곳으로 옮겨도 됩니다.
  • 도메인은 필수가 아닙니다. 사고 싶으면 안내판 값에 도메인을 넣으면 끝.

서버를 옮기는 날 — 순서

  1. 새 서버를 준비하고 옛 서버는 아직 끄지 않는다.
  2. 이 페이지 「원격 설정」에서 데이터 주소·API 주소를 새 것으로 바꾸고 「올리기」.
  3. 끝. 다음 실행부터 모든 앱이 새 서버로 갑니다. 며칠 뒤 옛 서버를 정리합니다.

안전장치 (앱 안에 들어 있음)

예비 안내판안내판 주소가 2개 박혀 있어 하나가 죽어도 다른 쪽에서 읽습니다.
마지막 값 기억읽은 안내판을 폰에 저장합니다. 안내판이 잠깐 안 되면 저장값으로 동작합니다.
내장 기본값첫 설치·오프라인이면 앱에 든 기본 주소를 씁니다.

어디에 뭐가 있나

비공개 소스 저장소파이프라인·앱 코드·정본 데이터(자치구 조각). 공개하지 않습니다. 주간 배치(GitHub Actions)가 여기서 돌아 데이터 서버로 올립니다.
안내판 저장소이 파일(config.json) 하나. 이 관리자 페이지가 GitHub API로 고칩니다. 토큰은 관리자 브라우저에만 저장.
데이터 서버앱 껍데기 + 자치구별 데이터 조각 + 서비스 워커. 정적 파일이라 대역폭만 있으면 됩니다.
API 서버로그인·후기·순위·건의. 개인정보는 닉네임과 메일 해시만. 서비스 종료 시 전부 삭제.

둘로 운영 (사내용 · 일반용)

데이터는 서울 전체 한 벌이고 앱마다 범위만 다릅니다(사내용 = 종각·종로·을지로·명동). 안내판은 앱마다 파일 하나(aibk.json / hanki.json), 계정·후기 데이터는 서로 섞지 않습니다.
